# Wi-Fi 相册

在 Windows 或 Mac 上运行，手机连接同一 Wi-Fi 后，通过浏览器查看电脑里的照片和视频。每台电脑自行选择媒体目录，可以随时增删；程序不绑定任何预设目录。

## 功能

- 目录首页和子文件夹分别显示图片、视频数量（含子文件夹），统计在后台更新；支持逐层浏览和跨目录「全部媒体」。
- 点「选择」可选中多个文件夹或整个媒体目录，再点「隐藏」；隐藏内容不参与显示和统计，可从「已隐藏」逐个或全部恢复。显示设置保存在这台电脑，手机刷新和服务重启后仍保留。
- 浏览时可用「全部 / 图片 / 视频」切换分类，分类在切换目录时保留。
- 图片与视频缩略图、左右滑动切换、视频播放与拖动进度。预览支持每次旋转 90°、全屏，旋转只作用于显示。
- 保留相邻图片，切换和横竖屏变化时复用已加载的画面；仅当前视频加载原文件。电脑也可用左右方向键切换、R 旋转、F 全屏。
- 适合 iPhone 的苹果风格界面，可以添加到主屏幕。
- 登录后记住 90 天；修改密码后旧登录立即失效。
- 媒体原文件只读；手机只能访问主动添加的目录。
- 按图片、视频扩展名白名单显示和读取文件；文档、压缩包、程序等不显示，直接请求原文件也会被拒绝。
- 添加、移除目录立即生效，无需重启。
- 目录统计在后台更新，刷新文件夹只读取当前目录；首次统计期间可继续浏览。缩略图分批加载，视频仅预加载当前项。

## Windows 开始使用

需要 Python 3.10 或更高版本，安装时勾选 **Add Python to PATH**。

1. 登录 GitHub，下载或克隆这个项目，在 Windows Codex 中打开。
2. 双击 `setup.bat`，安装运行依赖。图片、HEIC 和视频缩略图的依赖会一起安装。
3. 双击 `add-folder.bat`，在弹出的窗口中选择你希望浏览的媒体目录。可以重复添加多个目录。
4. 双击 `start.bat`，窗口会显示手机访问地址、用户名和随机生成的密码。
5. 手机连接同一 Wi-Fi，在浏览器中打开显示的地址并登录。

停止服务时双击 `stop.bat`。电脑重启后，再次双击 `start.bat` 即可。

系统防火墙首次提示时，允许相册在**专用网络**上通信。视频能否播放取决于手机浏览器对原视频编码的支持，程序不会转码或改动原视频。

先旋转视频，再点预览顶部的「全屏」，会保留旋转角度和播放进度。视频使用悬浮玻璃控制栏，保留苹果风格的播放、暂停与声音图标。前后跳转 10 秒的数字居中放在箭头环内，触屏按钮扩大点按范围，并显示跳转后的时间；支持选择常用播放速度，电脑上还可调整音量。顶部显示文件名与序号，进度条分别表示已播放和已缓冲的部分，持续缓冲时显示提示。

用鼠标或手指拖动进度条会先预览目标时间，松手后定位；取消拖动不改变进度，键盘调整仍立即生效。视频全屏时也可在画面上左右拖动定位，图片与普通预览仍左右滑动切换文件。点左侧锁图标可锁定播放器，避免误触暂停、跳转、旋转或切换；再点同一图标解锁，电脑上也可按 Esc 解锁。切换文件或关闭预览会清除锁定。

单击视频画面即时播放或暂停，双击进入或退出全屏，保留双击前的播放状态。播放直接响应点击，以兼容 iPhone Safari 的有声视频播放要求。鼠标左键或手指在视频画面按住 300ms 后临时以 2 倍速播放，顶部显示「2.0x 倍速播放」；松开、滑出画面、操作取消或切换媒体时恢复长按前的速度（例如 1.5 倍），不跳转进度或重新加载视频。暂停时长按可临时播放，松开恢复暂停；浏览器阻止这种播放时，先点播放按钮。控制条独立操作，不会触发长按。加载、解码或格式不兼容时会显示对应提示。

支持网页全屏的浏览器会铺满屏幕；iPhone Safari 使用页面内全屏，保留旋转和上述手势。需要隐藏 Safari 地址栏时，请「分享」→「添加到主屏幕」后打开相册。

其他操作可在项目目录的 PowerShell / 命令提示符中执行：

```powershell
.\run.bat list
.\run.bat add "D:\Photos" --name "我的照片"
.\run.bat remove 0
.\run.bat status
.\run.bat passwd
.\run.bat clear-cache
```

这些路径只是使用示例，请换成你自己的目录。`remove` 只移除相册中的目录登记，原文件保留。

## Mac 开始使用

```bash
python3 -m venv .venv
.venv/bin/python -m pip install -r requirements.txt
.venv/bin/python gallery.py choose
.venv/bin/python gallery.py start
```

也可用 `add "目录路径"` 添加目录。其他命令为 `list`、`remove`、`stop`、`status`、`passwd` 和 `clear-cache`。

Mac 保留系统自带的缩略图方式，另有跨平台图片与视频处理作为补充。已有配置继续使用。

## 地址、登录与主屏幕

- 默认地址：`http://电脑的局域网IP:9265`，`start` / `status` 会显示实际地址。
- 默认用户名：`gallery`；首次使用自动生成密码，`start` 会显示。
- 用 `passwd` 生成新随机密码，或 `passwd 新密码` 设置自己的密码。
- 浏览器访问 `/logout` 可以退出。
- iPhone Safari 登录后，点「分享」→「添加到主屏幕」，即可从主屏幕打开相册。

## 每台电脑独立配置

首次运行会自动生成 `config.json`，包含这台电脑的登录信息和媒体目录。仓库提供 `config.example.json` 作为配置格式示例，通常无需手动复制；空密码和空密钥会在首次运行时自动生成。

程序代码和界面保存在 GitHub。媒体文件、媒体目录配置、登录密码、缩略图缓存、日志和进程状态只留在各自电脑上，均已加入 `.gitignore`。

隐藏文件夹的显示设置单独保存在 `.view-settings.json`，也不进入版本控制；隐藏和恢复不会修改目录登记或原文件。隐藏用于整理相册显示，已知媒体链接仍遵循已添加目录的访问权限。

两台电脑可以使用相同功能，同时管理各自选择的内容。后续更新程序时，先停止相册，再执行 `git pull`，更新依赖后重新启动。

## 给 Windows Codex 的接手说明

## 开发验证

```bash
python -m pip install -r requirements.txt
python -m unittest discover -s tests -v
```

已安装 Node.js 时，可运行 `node tests/test_frontend.cjs`，验证分类、目录计数更新、旋转、全屏、长按与双击、播放控制、滑动切换和加载行为。

测试使用临时配置和生成的媒体文件。GitHub Actions 在 Windows 上验证启动、重复启动、状态查询、停止、登录、目录浏览、原文件只读、范围请求和缩略图。
